# analysis-dashboard Spec Delta

## ADDED Requirements

### Requirement: AI 盤後戰略解讀卡片
系統 SHALL 在個股深度分析分頁中提供「AI 盤後戰略解讀」專屬卡片，包含一鍵生成按鈕、載入打字機動畫、Markdown 結構化排版與重新生成控制項。

#### Scenario: 初始狀態呈現一鍵生成按鈕
- **WHEN** 使用者進入「個股深度分析」分頁且尚未對該標的生成 AI 戰略
- **THEN** 頁面顯示「🤖 AI 盤後戰略解讀」卡片與「一鍵生成戰略分析」按鈕

#### Scenario: 點擊生成並展示打字機串流
- **WHEN** 使用者點擊「一鍵生成戰略分析」
- **THEN** 卡片進入生成狀態，並逐字流式渲染 AI 輸出的進場時機、建議價位與訊號警示

#### Scenario: 缺少 API 金鑰友善提示
- **WHEN** 使用者點擊生成但後端回傳金鑰未配置提示
- **THEN** 卡片醒目標示金鑰配置引導，保留既有各項技術圖表與三層檢驗結果不變
