# Spec Delta

## ADDED Requirements

### Requirement: 加權指數日線資料
系統 SHALL 能夠同步並快取台灣加權指數（TAIEX）最近 5 年的日線收盤資料，並且和個股資料一樣做增量更新，只抓取快取最後日期之後的資料，供大盤多空相關計算使用。

#### Scenario: 首次同步加權指數
- **WHEN** 本機快取中沒有任何加權指數資料，而系統需要大盤資料
- **THEN** 系統抓取最近 5 年的加權指數日線並存入本機快取

#### Scenario: 增量同步加權指數
- **WHEN** 本機快取中已有加權指數資料，最後日期早於最近一個已收盤的交易日
- **THEN** 系統只請求最後日期之後的資料，並合併進快取

#### Scenario: 額度用盡時使用快取
- **WHEN** 同步加權指數時，外部 API 回報額度用盡，但本機已有快取
- **THEN** 系統沿用既有快取繼續計算，並標示大盤資料的截止日
