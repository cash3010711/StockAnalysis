# Proposal

## Why

目前要判斷一檔台股的進出場時機，得分別查看技術線圖、法人籌碼與財報，再憑感覺整合，結果無法驗證。這個工具輸入一檔股票就能整合三個面向、給出具體點位，並附上可重現的歷史回測勝率，讓每個建議都有數據根據。

## What Changes

- 新增本機執行的 Web App（後端 API + 前端頁面），專案目前是空的，從零建立。
- 用股票名稱或代號查詢上市、上櫃普通股，支援自動完成。
- 從外部資料源取得日 K、三大法人、融資融券、月營收、季財報，並快取在本機，只增量補抓。
- 三層分析：
  - 基本面：體質過濾。
  - 籌碼面：確認條件。
  - 技術面：5 個固定參數的策略（含布林通道壓縮突破）產生進場訊號，並以 ATR 算出停利、停損價。
- 今天有訊號就顯示進場價、停利、停損；沒有訊號就顯示「觀望」、觸發條件價位，以及未通過的條件。
- 每個策略都在過去 3–5 年資料上回測：
  - 顯示勝率、交易筆數、平均報酬、期望值、最大回檔。
  - 樣本不足時另外標示。
  - 並排顯示「純技術面」的對照結果。
- K 線圖標示歷史回測交易與今日點位。

## Capabilities

### New Capabilities
- `stock-lookup`：以名稱或代號查詢股票，提供自動完成；限上市、上櫃普通股。
- `market-data`：取得並快取價格、籌碼、基本面資料，處理資料缺漏、API 額度與憑證錯誤。
- `signal-analysis`：三層條件評估，產生今日進場點位或觀望狀態與觸發條件。
- `strategy-backtest`：各策略的歷史回測與勝率統計，包含避免偷看未來的規則與交易成本。
- `analysis-dashboard`：呈現分析結果、回測統計與 K 線標記的頁面。

### Modified Capabilities
（無，專案目前沒有既有規格）

## Out of Scope

- 全市場選股掃描（一次分析所有股票）。
- 盤中即時報價與即時訊號；只用收盤後的日資料。
- 自選股清單，以及 LINE／Email 通知。
- 在介面上自訂策略與參數。
- ETF、權證、興櫃股。
- 自動下單與串接券商。
- 放空訊號、多使用者、登入、對外公開部署。

## Impact

- 新增後端（Python）與前端（TypeScript）兩個專案目錄，以及本機 SQLite 快取檔。
- 新增外部相依：FinMind API，需要使用者自行申請免費 token，並受每小時請求額度限制。
- 只在 Windows 本機執行，不影響其他系統。
