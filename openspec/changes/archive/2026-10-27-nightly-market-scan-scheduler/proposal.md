# Proposal: 兩階段全市場掃描與夜間自動備戰排程

## Why

目前系統在執行全市場掃描時，逐檔向 FinMind 發出同步請求，極易在掃描數十檔後耗盡免費 API 額度並觸發斷路器（Circuit Breaker）降級為本地快取，導致後續標的無法取得當日最新盤後數據，使隔日進出場決策存在行情時效風險。為滿足使用者每晚掃描全台股、挑選潛力股並產生隔日作戰點位的習慣，需要引進兩階段過濾機制與夜間自動化排程。

## What Changes

- **兩階段掃描流程（Two-Stage Pipeline）**：
  - **第一階段（廣度快篩）**：透過台灣證交所與櫃買中心（TWSE/TPEx）每日盤後公開成交總表，單次批次獲取全市場 1,800+ 檔當日價量數據，過濾成交量不足（如 < 1000 張）或未達門檻標的，初步選出 30~50 檔候選股。
  - **第二階段（深度分析）**：僅針對通過初篩的候選股調用 FinMind API 進行增量同步（日K、三大法人、融資券），完成三層濾網與回測驗證，大幅降低 API 請求次數至 100 次以內。
- **夜間自動排程與隔日作戰清單（Nightly Scheduler & Action Plan）**：
  - 每日 18:30 自動於背景執行兩階段全市場掃描與點位計算。
  - 生成「次日作戰清單」，提供進場價、停損價、停利目標價與勝率，使用者開啟系統即可直接檢閱。

## Capabilities

### New Capabilities
- `nightly-scheduler`: 提供每日盤後定時自動執行全市場篩選、保存掃描結果與生成隔日交易備戰清單之能力。

### Modified Capabilities
- `market-scanner`: 擴充支援兩階段篩選機制（結合證交所公開總表快篩與 FinMind 精準增量同步），並輸出整合隔日作戰點位之結果。

## Out of Scope

- 不包含全自動串接券商 API 下單或即時盤中自動跟單功能。
- 不支援 macOS 與 Linux 特有之排程工具（依專案規範僅支援 Windows 環境）。
- 不更動歷史回測與三層評估核心算法之數學定義。

## Impact

- **後端模組**：新增證交所/櫃買當日盤後總表抓取器、更新 `DataService` 與 `scanner.py`、新增 APScheduler 或 Windows 背景定時工作模組。
- **前端介面**：市況掃描器新增「兩階段掃描」模式選項與「昨日夜間自動掃描結果」檢視面板。
- **外部依賴**：新增對證交所/櫃買公開 OpenAPI 或盤後總表端點的輕量 HTTP 請求。
