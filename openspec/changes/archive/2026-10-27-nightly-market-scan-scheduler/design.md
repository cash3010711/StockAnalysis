# Design: 兩階段全市場掃描與夜間自動備戰排程架構

## Context

見 `proposal.md`。當前系統在全市場掃描時對每檔股票單獨請求 FinMind API，遇到免費方案配額耗盡即啟動斷路保護（Circuit Breaker）並降級為本地快取，使當日最新盤後數據缺漏。本設計旨在透過公開盤後總表快篩與精準增量同步，徹底消除額度耗盡問題，並提供背景定時運作能力。

## Goals / Non-Goals

**Goals:**
- 將全市場每日掃描之外部 API 請求數由 5,000+ 次降低至 150 次以內。
- 確保所有入選隔日作戰清單的標的 100% 具備當日最新收盤價與籌碼數據。
- 每日 18:30 在 Windows 後端背景自動排程執行選股與點位計算，並持久化至本地 SQLite。
- 前端提供夜間作戰清單面板，直接呈現進場、停損與停利目標價。

**Non-Goals:**
- 不涉及自動下單或串接券商下單 API。
- 不引入重型分散式排程器（如 Celery/Redis），維持單機純 Python + SQLite 架構。
- 不改變技術指標與回測引擎核心數學邏輯。

## Decisions

### 1. 第一階段廣度快篩資料源：TWSE / TPEx 公開盤後總表
- **決策**：在 `app/data` 新增 `twse_client.py`，於每日 15:00 後透過 TWSE 與 TPEx 之公開盤後行情端點（例如 TWSE `MI_INDEX` 與 TPEx `afterTrading_dailyQuote`）單次取得上市櫃所有普通股當日開高低收與成交量。
- **替代方案評估**：
  - *全走 FinMind*：全市場 1,800 檔每檔 1 次請求即需 1,800 次，遠超免費配額（每小時 600 次），不可行。
  - *僅依賴本機舊快取*：無法獲取「今天盤後」第一手大漲或放量突破標的，存在嚴重時效延遲。

### 2. 第一階段快篩邏輯與收斂標準
- **決策**：第一階段過濾條件為：
  1. 當日成交量 >= 1,000 張（過濾殭屍股與流動性不足標的）。
  2. 當日收盤價 >= 10 元且收紅棒或上漲突破。
  3. 依漲幅或爆量倍數取前 50 檔最具爆發力標的作為第二階段輸入池。
- **好處**：將標的池精確收斂在 30~50 檔，確保第二階段同步所需 FinMind API 請求在 100~150 次內（免費配額可輕鬆承受）。

### 3. 第二階段深度分析與隔日作戰點位生成
- **決策**：對候選標的調用 `DataService.sync_stock`，增量寫入日K、三大法人與融資券，並呼叫 `assembler.py`、`indicators.py` 及 `exits.py` 計算具體點位：
  - 建議進場價：以隔日開盤或次日限價委託評估。
  - 停損價：跌破近期支撐或 -2.0 ATR。
  - 停利價：預設 +3.0 ATR（或波段滿足點）。
  - 風險報酬比與歷史回測勝率。

### 4. 背景定時排程：FastAPI Lifespan + APScheduler
- **決策**：使用 `APScheduler` 的 `AsyncIOScheduler` 或 `BackgroundScheduler` 掛載於 FastAPI `lifespan` 生命週期，設定於每週一至週五 18:30 自動執行。
- **休市判斷**：若公開盤後資料未更新或為週末國定假日，排程器自動跳過。

### 5. 本機持久化存儲：`nightly_plan` 資料表
- **決策**：在 `cache.db` 新增 `nightly_plans` 與 `nightly_plan_items` 表，記錄掃描日期、觸發策略、評估點位、回測勝率與產生時間，提供 `/api/scanner/nightly-plan` 端點供前端載入。

## Risks / Trade-offs

- **[證交所公開端點格式變更或防爬機制]** → 加入 HTTP User-Agent、重試機制與備用鏡像端點解析，若失敗時平滑降級提示。
- **[使用者在 18:30 未開機]** → 排程器於開機啟動時自動檢查今日若未跑過夜間掃描（且當前時間已過 15:30 交易日），提供「補跑」按鈕或自動執行補償掃描。
- **[FinMind API 短暫離線]** → 個別候選股若同步失敗，標記同步異常並跳過，不影響其餘標的生成點位。

## Migration Plan

1. 後端安裝 `apscheduler` 依賴。
2. 資料庫執行 schema migration 新增作戰清單表。
3. 實作證交所公開總表抓取器與排程服務。
4. 前端新增夜間掃描結果展示卡片。
