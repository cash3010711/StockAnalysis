# Spec Delta: market-scanner

## ADDED Requirements

### Requirement: 兩階段全市場快篩與深度同步流水線
系統 SHALL 提供兩階段選股流水線模式。第一階段利用證交所（TWSE）與櫃買中心（TPEx）每日盤後公開成交總表，對全市場標的進行成交量（例如 >= 1,000 張）與漲幅門檻快篩，將標的快速收斂；第二階段僅針對通過初篩之候選標的調用 FinMind API 執行增量資料同步與三層濾網回測。

#### Scenario: 啟用兩階段全市場快篩模式
- **WHEN** 使用者選擇全市場股票池並啟用「兩階段快篩」
- **THEN** 系統第一階段以 TWSE/TPEx 公開總表過濾出候選標的，第二階段僅針對候選標的進行 FinMind 同步與三層濾網運算，全市場掃描請求總數維持在 200 次以內且不觸發額度中斷

### Requirement: 隔日交易作戰點位輸出
系統 SHALL 為篩選出的每檔潛力標的依據 ATR 波動度與收盤價計算隔日建議進場價、嚴格停損價、停利目標價與預計持有天數，提供直觀的作戰參數。

#### Scenario: 產出具體進出場價格與風控參數
- **WHEN** 標的通過技術策略與三層檢驗
- **THEN** 結果表格清楚呈現建議進場價格、停損價格、停利價格與最大持有天數，輔助使用者設定次日委託單
