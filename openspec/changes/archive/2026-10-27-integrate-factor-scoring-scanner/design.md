# Design

## Context

在 Change A 中，我們完成了 5 年跨股票的因子事件研究（131 檔標的，15.6 萬日線樣本），證實以下核心結論：
1. **最強正向因子**：相對強度 RS 前 20%（lift 1.78~2.04）、帶量突破 20 日新高（lift 1.50）、布林通道壓縮突破（lift 1.43）、營收創新高（lift 1.43）、營收加速（lift 1.21）。
2. **無效或有害因子**：均線多頭拉回 20MA（lift 0.64）、負債比 < 60%（lift 1.02 無效且排除金融股）。
3. **多因子評分效果**：前 10% 高分群起漲命中率達 24.94%（相對於市場基準 12.48%，lift 達 2.00x），且十分位組命中率嚴格單調遞減。

目前市場掃描器（`scanner.py`）與兩階段快篩（`twse_client.py`）尚未接入這套評分體系，仍以「當日漲幅前 50」及「單股自身稀少回測次數」排序。

## Goals / Non-Goals

**Goals：**
- 在後端分析與掃描流程中，即時計算每檔股票的「多因子起漲評分 (0–100)」、「十分位組別 (1–10)」、「歷史起漲機率 (%)」與「觸發強因子標籤清單」。
- 改造兩階段掃描的第一階段快篩：預設以純流動性門檻（成交量 >= 1000 張、收盤 >= 10 元，依成交量或流動性排序），消除「當日大漲才選」的追高偏差；並保留 legacy 模式。
- 升級前端掃描結果表格：增加「起漲評分」欄位，顯示命中率與因子徽章，並預設支援依起漲評分由高至低排序。

**Non-Goals：**
- 不廢棄個股原本的 5 年回測技術策略與 ATR 點位（使用者仍需知道進出場價格與停損位置）。
- 不更動 FinMind API 資料同步排程或資料庫既有結構。

## Decisions

### D1：凍結權重與評分器封裝 (`app.analysis.factor_scorer`)
在 `backend/app/analysis/factor_scorer.py` 建立常數字典與輕量評分器：
- 權重來源：Change A 訓練期實證係數（RS 前 20%: 0.711, 帶量突破 20 日: 0.393, 布林壓縮突破: 0.390, 營收創新高: 0.293, 營收加速: 0.259, 營收年增正: 0.196, 法人 10 日買超: 0.139, 法人佔均量: 0.084, 大盤多頭: 0.059）。
- 正規化參數：`q01 = 0.0`, `q99 = 1.95`，映射到 0–100。
- 十分位對照表：
  - Decile 1 (Score ≥ 76.7): 歷史起漲率 24.9% (Lift 2.00x)
  - Decile 2 (Score 56.9 ~ 76.7): 歷史起漲率 19.7% (Lift 1.58x)
  - Decile 3 (Score 42.4 ~ 56.9): 歷史起漲率 13.7% (Lift 1.10x)
  - Decile 4–10: 歷史起漲率 7.8% ~ 11.1%
- 單股評估函數：`evaluate_stock_score(stock_id, daily_k, monthly_revenue, institutional_investors, market_bull) -> Dict`

### D2：兩階段初篩模式重構 (`twse_client.filter_candidates`)
- 新增參數 `sort_by: str = "volume"` ("volume" | "change_pct") 與 `require_bullish: bool = False`。
- 預設模式（`sort_by="volume"`, `require_bullish=False`）：篩選 `volume_lots >= min_volume_lots` 且 `close >= min_price`，依成交量由大至小取前 `top_n`，確保高流動性標的全部入圍，不排除當日黑 K 或小幅盤整標的。
- 相容模式：保留當 `sort_by="change_pct"` 時的舊行為。

### D3：掃描結果資料結構擴充 (`scanner.py`)
在 `matched_data` 新增以下欄位：
```python
"factor_score": float,        # 0.0 ~ 100.0
"factor_decile": int,         # 1 ~ 10
"historical_hit_rate": float, # 例如 24.9
"triggered_factors": List[str] # 例如 ["RS前20%強", "帶量突破20日新高", "營收創新高"]
```
若掃描排序規則選擇多因子分數（預設或使用者點選），排序 key 以 `factor_score` 為最優先。

### D4：前端呈現升級
在前端 `ScanResultItem` 增加評分欄位：
- 表格新增「起漲評分」欄位，以色彩徽章呈現（綠/黃/紅等依分數區間區分，例如 ≥ 75 分標記為紫色或深綠高亮）。
- 游標懸停或欄位下方顯示「歷史起漲率 24.9% (2.0x)」。
- 展開或卡片標記處呈現觸發的強因子標籤。
- 點擊「起漲評分」標題支援升冪/降冪排序。

## Risks / Trade-offs

- **橫斷面 RS 在單股分析時的計算**：在全市場掃描時有完整股票池，可精確計算橫斷面百分位；在單股個別查詢時，若本機未載入全市場，RS 採用本機快取股票池或個股自身 120 日動能做平滑估計，並標註參考。
- **初篩放寬漲幅限制帶來的運算量**：第一階段依成交量取前 50 檔，進入第二階段的總量依然維持在 50 檔以內，FinMind 請求總數與運算耗時不變，不會對系統造成負擔。
