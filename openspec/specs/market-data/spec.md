# market-data Specification

## Purpose

取得分析與回測所需的台股日價格、籌碼與基本面資料，並快取在本機，讓重複查詢既快速又不浪費外部 API 額度。

## Requirements

### Requirement: 取得分析所需資料
系統 SHALL 為每檔分析的股票取得至少 5 年的下列資料：還原權值日 K（開高低收、成交量）、三大法人每日買賣超、每日融資融券餘額、月營收、季財報（EPS、負債比）。

#### Scenario: 首次分析一檔股票
- **WHEN** 使用者第一次分析 `2330`，且本機沒有任何該股資料
- **THEN** 系統取得上述五類資料，各涵蓋至少最近 5 年，並存入本機快取

### Requirement: 增量更新快取
系統 SHALL 在本機已有資料時，只取得快取最後日期之後的新資料，不重複下載已有的歷史資料。

#### Scenario: 再次分析同一檔股票
- **WHEN** 使用者分析 `2330`，本機快取的日 K 最後日期為前一個交易日
- **THEN** 系統只請求該日期之後的資料，並和快取合併

#### Scenario: 當日已是最新
- **WHEN** 本機快取已包含最近一個已收盤交易日的資料
- **THEN** 系統不向外部資料源發出日 K 請求

### Requirement: 保存基本面資料的公布日
系統 SHALL 為每筆月營收與季財報記錄其可被使用的生效日（公布日），供回測判斷某個日期當時能否取得該資料。

#### Scenario: 月營收生效日
- **WHEN** 系統存入 9 月營收資料
- **THEN** 該筆資料的生效日不早於 10 月 10 日（若資料源有實際公布日，則以實際公布日為準）

#### Scenario: 季財報生效日
- **WHEN** 系統存入第 2 季財報，且資料源沒有實際公布日
- **THEN** 該筆資料的生效日設為法定申報期限（8 月 14 日）

### Requirement: 缺少 API 憑證時給出明確錯誤
系統 SHALL 在缺少或無效的資料源 token 時停止取資料，並回報可操作的錯誤訊息，說明如何設定 token。

#### Scenario: 未設定 token
- **WHEN** 系統啟動時找不到資料源 token
- **THEN** 分析請求回傳錯誤「尚未設定 FinMind token」，並附上設定方式說明

### Requirement: 處理 API 額度用盡
系統 SHALL 在外部 API 回報額度用盡時停止重試，並告知使用者；如果已有快取，則用快取資料完成分析並標示資料日期。

#### Scenario: 額度用盡但有快取
- **WHEN** 外部 API 回報額度用盡，且本機有該股截至 3 天前的快取
- **THEN** 系統用快取完成分析，結果標示「資料截至 <快取日期>，API 額度已用盡」

#### Scenario: 額度用盡且無快取
- **WHEN** 外部 API 回報額度用盡，且本機沒有該股任何快取
- **THEN** 系統回傳錯誤「API 額度已用盡，請稍後再試」，不產生任何分析結果

### Requirement: 資料不足時標示
系統 SHALL 在某一類資料缺漏，或歷史長度不足 5 年時（例如新上市股票），仍回傳可計算的部分，並明確標示哪些資料不足。

#### Scenario: 上市未滿 5 年
- **WHEN** 分析的股票上市只有 2 年
- **THEN** 系統用全部 2 年資料計算，並標示「歷史資料僅 2 年」
