# market-scanner Specification

## Purpose
提供全市場與分層股票池（本機已快取、台灣 50、全市場上市櫃、產業分類）之波段條件掃描、即時串流進度回報、自訂三層與技術策略篩選，以及可排序的符合條件股票列表。

## Requirements

### Requirement: 股票池範圍與產業別選擇
系統 SHALL 允許使用者在執行選股掃描前選擇掃描股票池範圍，包含「本機已快取股票」、「熱門權值／台灣 50 代表股」、「全市場上市櫃普通股」、「僅上市普通股」與「僅上櫃普通股」，並提供簡化之產業類別過濾，僅區分「全部產業（不限）」、「科技股（電子八大類）」與「非科技股」。在兩階段快篩流水線模式下，系統 SHALL 在篩選前補齊候選標的之產業分類。

#### Scenario: 選擇本機已快取股票池
- **WHEN** 使用者選擇「本機已快取股票」並啟動掃描
- **THEN** 系統僅針對本機資料庫中已有歷史日 K 資料之普通股進行掃描

#### Scenario: 依產業類別過濾
- **WHEN** 使用者選擇特定產業分類選項（全部產業、科技股或非科技股）並啟動掃描
- **THEN** 系統僅掃描符合該產業分類範圍之支援普通股

#### Scenario: 依科技股產業類別過濾
- **WHEN** 使用者選擇「科技股（電子八大類）」並啟動掃描
- **THEN** 系統僅掃描屬於半導體、電腦周邊、光電、通信網路、電子零組件、電子通路、資訊服務、其他電子業之普通股標的

#### Scenario: 依非科技股產業類別過濾
- **WHEN** 使用者選擇「非科技股」並啟動掃描
- **THEN** 系統僅掃描排除電子八大類以外之傳產與金融上市櫃普通股標的

#### Scenario: 兩階段快篩啟用科技股過濾
- **WHEN** 使用者啟用兩階段快篩並選擇「科技股」
- **THEN** 系統於初篩結果關聯補齊產業分類，正確篩選出符合條件之科技股標的，不因原始資料無產業別而全部排除

### Requirement: 快取極速掃描與自動同步降級模式
系統 SHALL 提供「僅掃描本機快取」與「自動同步最新資料」兩種資料模式。當開啟「自動同步最新資料」且掃描過程中遭遇 FinMind API 請求額度上限（HTTP 402 或 Quota Exceeded）時，系統 SHALL 自動將後續標的降級為使用本機現有快取完成掃描，並於介面顯示額度耗盡與降級提示，不得直接中斷或丟棄已掃描之結果。

#### Scenario: 僅掃描本機快取模式
- **WHEN** 使用者選擇「僅掃描本機快取」並執行掃描
- **THEN** 系統不對外部 API 發出任何同步請求，直接以本機快取資料完成評估

#### Scenario: 自動同步途中遇到 API 額度上限
- **WHEN** 使用者開啟「自動同步最新資料」且在掃描第 N 檔時觸發 FinMind 額度上限
- **THEN** 系統保留已得結果、後續標的自動改讀本機快取繼續掃描，並在頁面上顯示 API 額度上限提示訊息

### Requirement: 彈性三層檢驗與技術策略篩選組合
系統 SHALL 預設篩選同時符合「基本面合格」、「籌碼面合格」且「最近一個交易日有任一技術策略觸發進場訊號」的股票；同時 SHALL 允許使用者在介面上自由勾選是否要求「基本面合格」、是否要求「籌碼面合格」、是否要求「股價站上 60MA 季線」，以及指定技術策略組合。

#### Scenario: 預設三層完整檢驗掃描
- **WHEN** 使用者維持預設條件（勾選基本面合格、籌碼面合格、任一策略觸發）執行掃描
- **THEN** 結果列表僅列出基本面通過、籌碼面通過、且當日至少有 1 個技術策略觸發進場訊號之股票

#### Scenario: 放寬基本面並指定單一技術策略
- **WHEN** 使用者取消勾選「基本面合格」並僅勾選「帶量突破20日新高」策略
- **THEN** 系統列出所有籌碼面合格且當日觸發「帶量突破20日新高」訊號之股票（即使基本面未通過亦列出，並標示基本面未過）

#### Scenario: 要求股價站上 60MA 季線
- **WHEN** 使用者勾選「站上 60MA 季線」篩選條件執行掃描
- **THEN** 系統僅篩選出最新收盤價大於或等於當日 60MA 季線之標的，過濾掉均線呈空頭排列之個股

### Requirement: 即時掃描進度回報與中止機制
系統 SHALL 在掃描執行期間即時顯示已掃描檔數、總檔數、目前掃描標的與已符合檔數，並於每找到一檔符合條件之股票時即時動態加入結果列表中；使用者 SHALL 可隨時點擊「中止掃描」停止後續掃描並保留目前已找到的結果。

#### Scenario: 即時串流更新進度與結果
- **WHEN** 掃描正在進行中且發現一檔符合條件之股票
- **THEN** 進度條即時更新完成比例，且該檔股票立即出現在下方結果表格中，無須等待全部股票掃描完畢

#### Scenario: 手動中止掃描
- **WHEN** 使用者在掃描進行中點擊「中止掃描」
- **THEN** 系統立即停止後續標的之請求與掃描，並保留畫面上目前已篩出的符合股票列表

### Requirement: 符合條件股票列表與排序
系統 SHALL 以表格列出所有符合條件之股票，每列包含：收藏星號（⭐）按鈕、股票代號與名稱（含上市／上櫃與產業標籤）、收盤價與評估日、起漲潛力評分（0–100 分）、跨股票歷史起漲命中率（如第 1 組 24.9%）、今日觸發之技術策略標籤與關鍵強因子標籤、建議進場／停損／停利價、基本面指標摘要（月營收年增率、近四季 EPS）、籌碼面指標摘要（近 10 日法人買賣超張數、融資增減率）、以及觸發策略之歷史回測勝率與平均報酬率，並支援依起漲潛力評分、勝率、平均報酬率、收盤價、法人買超、營收年增率或股票代號排序。在夜間作戰清單中亦同步提供收藏星號（⭐）按鈕。

#### Scenario: 依起漲潛力評分排序
- **WHEN** 使用者點擊結果表格的「起漲評分」欄位標題
- **THEN** 表格依多因子起漲評分由高至低重新排序顯示，最高分者列於最前

#### Scenario: 呈現跨股票歷史起漲命中率
- **WHEN** 某標的符合條件且其多因子評分落入第 1 十分位組（前 10%）
- **THEN** 結果表格顯示其起漲評分及對應之跨股票歷史命中率（約 24.9%）與表現倍數（約 2.0x），輔助使用者評估其起漲機率

#### Scenario: 依歷史回測勝率排序
- **WHEN** 使用者點擊結果表格的「歷史回測勝率」欄位標題
- **THEN** 表格依觸發策略之歷史回測勝率由高至低（或由低至高）重新排序顯示

#### Scenario: 於即時掃描結果清單一鍵加自選
- **WHEN** 使用者在掃描結果清單點選某檔股票之空心星號按鈕
- **THEN** 系統將該股票加入自選股公用池，星號轉為實心高亮，並同步更新頂部自選股計數

#### Scenario: 於夜間作戰清單一鍵加自選
- **WHEN** 使用者在夜間隔日作戰清單點選某檔推薦標的之星號按鈕
- **THEN** 系統將該推薦股票加入自選股公用池，保持收藏狀態即時回饋

### Requirement: 兩階段全市場快篩與深度同步流水線
系統 SHALL 提供兩階段選股流水線模式。第一階段利用證交所（TWSE）與櫃買中心（TPEx）每日盤後公開成交總表，對全市場標的進行流動性快篩（成交量 >= 1,000 張且股價 >= 10 元），淘汰「必須收紅且依當日漲幅取前 50」的單一追高限制，避免過濾掉整理起漲或拉回標的；同時保留 legacy 模式供選擇。第二階段僅針對通過初篩之候選標的調用 FinMind API 執行增量資料同步、三層檢驗與多因子評分。

#### Scenario: 啟用兩階段全市場快篩模式
- **WHEN** 使用者選擇全市場股票池並啟用「兩階段快篩」
- **THEN** 系統第一階段依流動性篩選候選標的，第二階段針對候選標的進行 FinMind 同步、三層濾網與多因子評分，全市場掃描請求總數維持在 200 次以內且不觸發額度中斷

#### Scenario: 篩選整理中未大漲標的
- **WHEN** 全市場某檔股票成交量達標（>= 1,000 張），當日小跌或小漲（非漲幅前 50 名），但型態符合突破或拉回策略
- **THEN** 系統第一階段不會因漲幅排名將其淘汰，候選標的順利進入第二階段並完成評分

### Requirement: 隔日交易作戰點位輸出
系統 SHALL 為篩選出的每檔潛力標的依據 ATR 波動度與收盤價計算隔日建議進場價、嚴格停損價、停利目標價與預計持有天數，提供直觀的作戰參數。

#### Scenario: 產出具體進出場價格與風控參數
- **WHEN** 標的通過技術策略與三層檢驗
- **THEN** 結果表格清楚呈現建議進場價格、停損價格、停利價格與最大持有天數，輔助使用者設定次日委託單
