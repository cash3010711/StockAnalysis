# nightly-scheduler Specification

## Purpose
提供每日盤後定時自動執行全市場篩選、保存掃描結果與生成隔日交易備戰清單之能力，確保使用者每晚登入即可直接檢視最新點位。

## Requirements

### Requirement: 每日定時背景自動掃描
系統 SHALL 在每個台股交易日 18:30 自動於背景觸發兩階段全市場掃描，完整擷取當日最新盤後價量與籌碼，並將分析結果持久化儲存於本機資料庫。

#### Scenario: 交易日夜間自動觸發
- **WHEN** 系統時間達到交易日 18:30 且外部盤後數據已產出
- **THEN** 系統自動啟動背景掃描任務，無需使用者手動開啟瀏覽器或按下掃描

#### Scenario: 非交易日跳過排程
- **WHEN** 系統時間達到週末或國定休假日 18:30
- **THEN** 排程器自動偵測非交易日並跳過執行，不浪費運算資源與 API 額度

### Requirement: 隔日作戰清單持久化與即時查詢
系統 SHALL 將每次夜間掃描所篩選出的精選潛力股票、進場點位、停損停利目標價與勝率保存為作戰清單記錄，並提供專屬 API 供前端隨時載入最新作戰清單。

#### Scenario: 使用者開啟系統檢視昨夜作戰清單
- **WHEN** 使用者於夜間或隔日開盤前開啟系統
- **THEN** 系統即時載入最近一次產出之隔日作戰清單，展示所有符合標的之點位與策略明細
