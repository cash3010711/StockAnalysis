# 台股波段策略分析儀 (Taiwan Stock Swing Strategy Analyzer)

提供台股（上市、上櫃普通股）波段交易策略分析與回測的本機 Web 應用工具。結合「基本面、籌碼面、技術面」三層檢驗與歷史回測統計，杜絕未來函數偏差。

## 系統架構

- **後端 (Backend)**: Python 3.12 + FastAPI + pandas + numpy + SQLite（套件管理：[uv](https://docs.astral.sh/uv/)）
- **前端 (Frontend)**: React 19 + TypeScript + Vite + TradingView Lightweight Charts（套件管理：npm）

## 申請 FinMind Token 步驟

本系統行情與財報資料來源為 FinMind 免費 API（每小時約 600 次請求額度）：

1. 前往 [FinMind 官方網站](https://finmind.github.io/) 註冊帳號。
2. 登入後至個人設定或 API 金鑰頁面取得您的 **API Token**。
3. 在專案根目錄或 `backend/` 目錄下建立 `.env` 檔案：
   ```powershell
   Copy-Item backend\.env.example backend\.env
   ```
4. 開啟 `backend/.env`，將取得的 Token 填入：
   ```ini
   FINMIND_TOKEN=貼上您的FinMindToken
   ```

> **注意：** `.env` 與快取資料庫 `data/cache.db` 已被 `.gitignore` 排除，不會被提交至版本控制中。

## Windows 環境需求 (Prerequisites)

## Windows 啟動前後端步驟

### 1. 啟動後端 API 服務

開一個 PowerShell 視窗：

```powershell
cd backend
uv run uvicorn app.main:app --reload --port 8000
```

> 第一次執行時，`uv` 會自動建立虛擬環境並安裝所有依賴套件。
> 也可以直接在專案根目錄執行：`uv run --project backend uvicorn app.main:app --reload --port 8000`

- 後端 API 網址：`http://127.0.0.1:8000`
- 健康檢查端點：[http://127.0.0.1:8000/api/health](http://127.0.0.1:8000/api/health)
- API 互動文件：[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

### 2. 啟動前端開發伺服器

另開一個 PowerShell 視窗：

```powershell
cd frontend
npm install
npm run dev
```

- 前端預設網址：`http://localhost:5173`（若 5173 埠號已被占用，Vite 會自動依序使用 5174）
- 前端已設定 `/api` 代理（Proxy）導向後端 `http://127.0.0.1:8000`，開啟頁面即可看到後端健康檢查狀態。

## 因子事件研究與多因子驗證 (Factor Event Study)

本系統提供台股波段選股因子的事件研究 (Event Study) 與樣本外驗證工具：

### 執行研究指令

```powershell
uv run --project backend python backend/scripts/run_factor_study.py
```

- **分析邏輯**：
  - 標籤定義：訊號日隔日開盤進場，20 個交易日內最高價達 `+15%` 且未先跌破 `-7%`。
  - 時間切分：2021-10 至 2024-12 為訓練期（自動扣除尾端 20 日空檔 Purge），2025-01 起為獨立樣本外測試期。
  - 因子評估：5 大技術策略、基本面、籌碼面、加權指數大盤多空、相對強度 RS、波動收斂 VCP 等。
  - 產出物：自動於 `backend/reports/` 產生 Markdown 格式分析報告，包含各因子 Lift 表、分數十分位表現與驗證結論。

## 整合驗證與回測正確性抽查紀錄 (Task 8)

### 1. 端到端分析驗證 (Task 8.1)

已針對上市代表股（`2330` 台積電、`2454` 聯發科）與上櫃代表股（`6488` 環球晶）執行端到端完整分析：
- **首次分析**：自動同步 FinMind 最近 5 年歷史日 K（1,213 根 K 棒）、三大法人買賣超、融資融券、月營收與季財報，並存入本機 SQLite 快取（耗時約 2.8 ~ 3.2 秒）。
- **二次查詢**：命中本機快取與增量日誌，無需重複下載，查詢於 **0.5 ~ 0.6 秒內** 即時回應。
- **三層檢驗與策略訊號**：正確輸出評估日、基本面（營收成長、4 季累計 EPS、負債比）、籌碼面（外資投信買超、融資增減）檢驗結果與 5 大技術策略點位及回測統計。

### 2. 回測正確性手算抽查 (Task 8.2)

以 `2330` 台積電之「**帶量突破20日新高**」策略（三層檢驗歷史交易）為例，抽查 3 筆不同年份與出場情境之交易明細，與原始歷史日 K 棒開高低收進行手算核對：

| 交易序號 | 進場日期 | 進場價（次日開盤） | 出場日期 | 出場價 | 出場原因 | 停損價 | 停利價 | 持有天數 | 毛報酬率 | 淨報酬率 | 勝負 |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **#1** | 2022-11-16 | **491.5** | 2022-12-13 | **471.5** | 屆滿 20 日收盤 | 462.0 | 536.0 | 20 日 | -4.07% | **-4.64%** | 負 |
| **#2** | 2024-09-23 | **971.0** | 2024-10-09 | **1035.0** | 觸及停利價 | 928.0 | 1035.0 | 11 日 | +6.59% | **+5.98%** | 勝 |
| **#3** | 2026-04-28 | **2245.0** | 2026-05-26 | **2270.0** | 屆滿 20 日收盤 | 2125.0 | 2425.0 | 20 日 | +1.11% | **+0.52%** | 勝 |

#### 手算核對邏輯：
1. **進場價確認**：
   - 2022-11-16 原始日 K：Open = 491.5，與進場價完全相符。
   - 2024-09-23 原始日 K：Open = 971.0，與進場價完全相符。
   - 2026-04-28 原始日 K：Open = 2245.0，與進場價完全相符。
2. **出場條件確認**：
   - 交易 #1：持有 20 個交易日未觸及停損 (462.0) 或停利 (536.0)，於第 20 日 (2022-12-13) 以收盤價 471.5 出場。
   - 交易 #2：2024-10-09 當日最高價 1035.0 觸及停利價 1035.0，以停利價 1035.0 出場。
   - 交易 #3：持有 20 個交易日於第 20 日 (2026-05-26) 以收盤價 2270.0 出場。
3. **交易手續費與稅負核對**：
   - 買進成本：`進場價 × (1 + 0.1425%)`
   - 賣出實收：`出場價 × (1 - 0.1425% - 0.3%)`
   - 淨報酬率：`(賣出實收 - 買進成本) / 進場價`
   - 交易 #1：`(471.5 × 0.995575 - 491.5 × 1.001425) / 491.5 = -4.64%`
   - 交易 #2：`(1035.0 × 0.995575 - 971.0 × 1.001425) / 971.0 = +5.98%`
   - 交易 #3：`(2270.0 × 0.995575 - 2245.0 × 1.001425) / 2245.0 = +0.52%`
   - **比對結果**：手算數值與回測引擎輸出數值誤差小於 `1e-4`，邏輯完全一致。
